# Fluid reference data

## Hydraulic references

`hydraulic-friction.json` is generated by `examples/Generate-Hydraulic-References.py` using Python Decimal at 60-digit precision, without production Java calls. It specifies Poiseuille friction below Reynolds 2,000, the project's cubic smoothstep blend from 2,000 to 4,000, and Swamee-Jain above 4,000. The latter relation is documented in [EPA EPANET 2.2 section 12](https://usepa.github.io/EPANET2.2/12_analysis_algorithms.html). The project blend is not EPANET's transition interpolation. Implicit Colebrook factors are separately bisected for turbulent points and retained as empirical-correlation comparisons, not an alternative numerical acceptance tolerance. Regeneration should produce an identical file.

## Water vapour and nitrogen references

`nitrogen-cp-checks.json` holds the ideal-gas Cp of CoolProp 8.0.0's Nitrogen.json alpha0 (Span et al. 2000) at the fit's check points; `water-vapor-checks.json` and `water-vapor-compression.json` hold IAPWS-95 (CoolProp 8.0.0 Water.json through the Java Helmholtz oracle) molar volumes and isothermal compressibilities, and the IAPWS R12-08 (2008) dilute viscosity at those densities. All three are written by `tools/open-thermo-data/derive.mjs` from `OpenThermoOracleProbe.java` output (batch 2026-11-04-open-thermo-data, O2); none is generated by the production implementation.

Until then they were NIST Chemistry WebBook values, built by `examples/Fetch-FluidSteamReferences.py` and `examples/Build-NitrogenFluidProperties.py`; the same equations give the same volumes to 1e-7, the compressibilities 0.021 % apart (the WebBook values were pressure differences, these are exact derivatives) and the nitrogen Cp within 0.032 %. O5 of the same batch (2026-11-05) removed those two scripts from the tree (local copies in the main checkout's `research/2026-11-04-open-thermo-data/nist-copies/examples/`; `git show f5f871c44:examples/<name>`); the raw downloads are in the main checkout's `research/2026-10-15-code-consolidation/fluid-reference-tsv/`.
