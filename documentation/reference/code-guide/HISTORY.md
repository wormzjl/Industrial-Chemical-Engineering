### Facts the old guide got wrong

The 2026-09-08 guide is out of date on these points:

- V1 `ColumnSimulation` is gone, and so is the V3 preconditioner framework (production and test tree). The one bubble-point projection is `V3ColumnCalculator.projectedSeedOrPrevious`.
- The column keeps no retained result. No block holds one since batch 2026-11-02-process-simulator (the calculator block, whose `tryBegin` cleared the display and whose loaded result showed as STALE, left); the simulator's stored results are state, dropped on a format or revision mismatch. The default route is `LNN_FIRST` (bundled model `icheme:v3-column-open-r34-u1-v2`, a 300,000-poll budget). There is no learned recovery stage (`RAMP_HANDOFF` is gone) and one correction rule (`Correction.PROGRESS`).
- Presets and packages come from the material-catalog JSON. A new column on the simulator's sheet and the column templates start from `medium_crude` / `tjl20_methane` (`default_column_preset`); Tia Juana is test data only. The server sends no preset list; the client loads presets from its own JSON libraries.
- Versions: `ColumnWire` carries the column input's `V3ColumnInput.SCHEMA_VERSION` 1 and no block holds a column (the calculator block's wire schema 18, protocol `"14"` and `DATA_VERSION` 12 left with it in batch 2026-11-02-process-simulator); the process simulator's packets `"3"`, sheet files format 2 (no compatibility), block body format 1 and run results format 3 (state); fluid checkpoint envelope 1, state format 47 and facts schema 24 (another state format, a changed property basis or a state that does not validate rebuilds the islands from the facts; a world saved at format 19 or older, before the envelope, is reset once, decision D4; a newer envelope or facts schema refuses the world), fluid menu protocol `fluid-24` (with the converter's view and edit; with the towers', heaters', chimneys' and noise watches; displays on `sight-glass-3`, `mover-4` (with the drivers' watch), `instruments-1`, `flare-2`, `still-1`; shaft speeds on `rotation-1`; tool settings on `pipeline-tool-5`, shared line commands on `lines-1`, controller/DCS on `control-5`), machine pages `machine-4` (its view gained the prime movers' fuel group in batch 2026-11-10-prime-movers without a bump), a pipe's `Joints`, `Paint` and `Secondary` NBT and the rack lane copy `rack-3`, equipment protocol `equipment-23` (with the far silhouette subscription) and shape fields 12, assembly protocol `assembly-6` and store `icheme_assemblies` format 2 (state), accessory store `icheme_accessories` facts schema 6 and state format 1 (a newer schema or field, an unknown name or damaged facts refuse the world; unusable state is dropped). `MAX_PUMPAROUNDS` is 4 and `MAX_SIDE_DRAWS` is 4 (3 before 0.8.0). Config `energy.joulesPerFE` 2.5, `energy.machinesNeedPower` true, `create.stressPerFE` 34.13, `machines.wear.*` (enabled, 2 h, 10 min). `solver.workers` defaults to 0 (automatic, up to 12), shared by column solves and fluid islands.
- REST and STEADY are now one certificate kind. The SLACK/TAUT vessel behaviour is one complementarity wall row (`PhaseLayout.wallRow`), not an enum mode.
- There are no causal modules, buffered transfers or module horizons in the fluid runtime.

### Misleading names (details in the chapters)

- `PassiveNetwork` also holds pumps and compressors. `Reservoir` means any node. A junction's `Inventory.internalEnergy` holds `m·h`.
- `FluidThermodynamics.thermodynamicRevision()` still starts `fluid-trbdf2-r1`, but the integrator is backward Euler. Checkpoints save the string in each package record and compare it at load.
- `FlowControl.Mode` ordinals (9 constants) are saved in checkpoints: the island unit's endpoint modes. Do not reorder or remove a constant without a format bump (format 11 removed the three velocity-limit modes; unit format 4 states the eight ordinals left; the process-control batch appended `VALVE_CONFLICT`, ordinal 8).
- The item id `pressure_control_valve` names the Control Valve. `FlowControl.PressureValve` (facts control `pressure_valve`) is the legacy valve: a saved one is converted once to a `ControlValve` (`InstrumentService.reconcileLegacyValves`, `bind`).
- `PengRobinsonKernel` is the one production PR78 kernel. The fluid `HydrocarbonModel` has its own package-private static pure-component Z (`pureLiquidCompressibility`) for the volume calibration, a copy of the old `PengRobinson78` rules; `SpinePackageData` calls it too. `PengRobinson78` itself is a test-tree oracle.
- `HydrocarbonModel` is the cubic model of every network package, the pilot's N2 and CO2 included.
- An accepted island interval's status still reads `FULL` (`ProcessSolveServices`), a name left from the removed approximate mode; the fluid screen shows "Ready.".
- `columnDensity` and "static column" in the fluid code (`PassiveStepSolver`, `NetworkReduction`) mean the fluid standing in a line or port (decision D34), not the distillation column.
- `V3WaterProperties` is a column class that serves the fluid network too (see [column-v3.md](column-v3.md)).
- `V3ColumnInput` keeps one shorthand constructor (side draws only; used by `V3HollandExample32.input`). No old save decodes through it.
- `V3InitializationOptions.Mode` (learned/classical route) and `V3ColumnInitializer.Mode` (classical seed kind) are different enums.
- `ScheduledTransfer` ("module boundary rates") has no runtime producer since the modules left; only tests create one.
- `EquipmentShape.diameter`, `tangentLength` and `support` are a unit's own sizes (a bay's width and length, a compressor's throws, a pump's discharge); only a drum and a column read them as a vessel's.
- `ShapeRasterizer.CellKey` coordinates are not always cell coordinates: a body cell's axial coordinate is `BODY − class` (negative).
- "Controller" (`Layout.controller()`) is a role of one shell cell, not a block.
- `EquipmentShape.Kind.unit()` is decided by ordinal (`>= EXCHANGER`).
- `UNBOUND: saved inventory retained` (`FluidWorldAuthority`) is a live consistency status, not compatibility: the registry holds a device where the world now has another block (e.g. an external `/setblock`).
