# Remaining plant dependencies on loaded chunks

All five findings below were subsequently addressed on the batch branch. [Corrections and regression results](CHUNK_DEPENDENCY_FIXES_REVIEW.md)

Reviewed implementation `155b7f744..c25abe8a0` on 2026-11-18. A high-effort Sol review and an independent source trace found the following gaps. These are source findings. The earlier 6,000-tick run established continuous burner supply and a fresh solve on a running column in one save. It exercised the engine set-point entry point directly. It did not operate the column remotely from the DCS or test all of its utility controls.

| Priority | Equipment and trigger | Expected behavior and observed code path | Proposed correction and regression |
|---|---|---|---|
| P1 | Exchanger or column-condenser valve after restart or a remote piping edit | A validated external bypass, ratio feed valve or condenser-water feed valve should keep its assignment. The fluid authority starts with an empty side-to-valve map. Replaying a saved assembly entry requires a loaded exchanger cell, and each side ID is read from a loaded node. Without the assignment the bypass switches to internal control, ratio regulation is absent, or condenser water follows the hydraulic line. In the other direction, reverting the stored report after a remote piping edit can leave the old assignment active when the shell is absent. | Derive side and valve IDs from the saved assembly, shape, instruments and registrations at startup and on invalidation. Check a cold restart with both sides absent, then edit a dependency with only its chunk loaded and verify the valve is released. [AssemblyService](../../src/main/java/com/wormzjl/icheme/runtime/assembly/AssemblyService.java#L436), [side IDs](../../src/main/java/com/wormzjl/icheme/world/level/block/EquipmentStructure.java#L229), [process operation](../../src/main/java/com/wormzjl/icheme/runtime/fluid/FluidWorldAuthority.java#L1765) |
| P1 | Water intake with a pool across a chunk boundary | Water availability should depend on 100 face-connected water blocks. The probe treats unloaded positions as dry. A recount with only 80 of 100 visible closes the intake. When the intake itself unloads, its 1,200-tick block recheck pauses and the engine continues using the last decision. | Query generated terrain without a ticket and re-evaluate the saved switch on relevant changes. The existing unit test explicitly expects the half-visible pool to close. Cover a physically unchanged pool through unload, cold restart and reload. [Probe](../../src/main/java/com/wormzjl/icheme/world/level/block/FluidDeviceBlock.java#L135), [switch](../../src/main/java/com/wormzjl/icheme/runtime/fluid/FluidWorldAuthority.java#L580), [existing test](../../src/test/java/com/wormzjl/icheme/runtime/fluid/WaterBodyTest.java#L57) |
| P2 | DCS operation of a remote column | A running column can still solve, but the console lists columns from weak references to live controller cells. Start, Stop and Apply use that cell as part of the connectivity check. A wired, unloaded column can disappear or return `NO DATA LINK`. Start also uses live block lookups for condenser banks, utility sides and pump casings. Those reads can request a FULL chunk even when the complete assembly report is available. | Address the column by saved host and master position. Resolve Start membership through recorded shapes and device IDs. Exercise all three commands from a loaded console and verify all remote chunks stay absent. [DCS list](../../src/main/java/com/wormzjl/icheme/runtime/control/ControlHosts.java#L521), [command gate](../../src/main/java/com/wormzjl/icheme/runtime/control/ControlService.java#L400), [Start](../../src/main/java/com/wormzjl/icheme/runtime/assembly/ColumnStarts.java#L87) |
| P2 | Single-block fluid devices in a pollution blast | With block damage enabled, a pipe that vanilla destroys normally releases its contents and leaves the fluid graph. If any chunk in the required explosion footprint is absent, the fallback burns the cloud and applies constructed-shell breaches. It skips the vanilla callback that ruptures and unregisters pipes, including pipes on the loaded side of the boundary. | Define the single-block damage decision and reconcile the resulting registered removal with the block when its chunk returns. Compare a filled line under the same blast fully loaded and across the boundary, including inventory and release accounting. [Blast dispatch](../../src/main/java/com/wormzjl/icheme/runtime/pollution/Blasts.java#L246), [single-block destruction](../../src/main/java/com/wormzjl/icheme/world/level/block/FluidDeviceBlock.java#L334) |
| P2 | Multi-node equipment binding when only a secondary node loads | The bind path already has saved registration IDs. It still reads the primary shell entity through the level when binding a secondary node. Minecraft 1.21.1 routes this through `Level.getChunkAt` and requests a FULL chunk. A cross-chunk equipment load can therefore bring the primary chunk back merely to bind a socket. | Build the engine binding from the saved IDs and update the primary block's local metadata when it loads. Test secondary-only loading on a two-sided exchanger. [ControlHosts](../../src/main/java/com/wormzjl/icheme/runtime/control/ControlHosts.java#L119), [load entry point](../../src/main/java/com/wormzjl/icheme/world/level/block/entity/EquipmentShellBlockEntity.java#L303) |

The assembly validation walk also explicitly returns `NotLoaded` where its path leaves the active chunks. This affects a fresh check or reconstruction of a missing assembly report. It is separate from the loss of real-valve control on a previously validated exchanger. [AssemblyWalker](../../src/main/java/com/wormzjl/icheme/runtime/assembly/AssemblyWalker.java#L172)

Older saves have a discovery limit. A creative source that was never registered and feeds only a foreign endpoint can be outside all the positions scanned during migration. Its own chunk must load once for registration. An old solid still normally imports its fuel from disk, but adoption requires the saved pot identity to match the cell. A world whose plant registrations have been reset needs chunk reconstruction. [Power migration](../../src/main/java/com/wormzjl/icheme/runtime/power/PowerNetwork.java#L192), [still migration](../../src/main/java/com/wormzjl/icheme/runtime/fluid/StillFuelInventory.java#L49), [chunk registration](../../src/main/java/com/wormzjl/icheme/runtime/fluid/ChunkBinding.java#L53)

Foreign FE capabilities and Create rotation have the agreed live-world boundary. The fixed pollution monitor's local lamp and horn and block-local visual updates also need a ticking or loaded block. The DCS pollution input and the alarm beacon's engine decision have separate saved-data paths. The review traced steady-state fluid and shaft equipment, power, heat units, columns, stills, converters, hoppers, instruments, controls, intake, and environmental damage. No new simulation or GameTest was run for this review.
