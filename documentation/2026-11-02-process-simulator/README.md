# 2026-11-02-process-simulator

Purpose: an in-game process simulator: a dedicated block, a drag-and-drop flowsheet with a palette below, feed streams from the Fluid Generator's page, every unit including the column, Run on the client, a Results tab, flowsheet files under `.minecraft/IChemE`, and a compatibility system (owner request 2026-11-02: "make some design drawings for me to approve before moving to implementation").

Status: In progress since 2026-11-02. The owner took decisions D1 to D22 on 2026-11-02, and D23 on 2026-11-03. W1 to W10, W10b, sizing's S1 to S3, S4a, S3b, S4b, S5 and S4c, and the cooler model's C1, C1b, C2 and C3 and the utility regulation's U1, U1b and U2 are built on the branch, with the device names' N1 (all but the screen entry, which waits for the owner's pick), which carries main 0.19.0, with column operation in it (D10). Not merged (branch `claude/in-game-process-simulator-93dd9a`). Index: [../INDEX.md](../INDEX.md).
