# P2 Client and tutorial review

Scope: `client/**` (195 files, 43 554 lines), `science/tutorial` (40 files, 4 665 lines), `science/display` (1 file, 56 lines). Base `5f61d3139`. Read-only review, Opus medium. Paths below are relative to `src/main/java/com/wormzjl/icheme/` unless they start with `src/test`, `tools` or `documentation`.

## 1. Summary

**What the area does.** It draws every IChemE screen through a Minecraft-free GUI kit (`client/gui/common/kit`) and builder classes, with the game's widgets at the builders' slots. It draws the world-side equipment: bodies, instruments, wiring, tanks, sight glasses, ghosts and effects. It keeps client copies of the state the server publishes, by watch sets and caches. It also holds the field guide: data, films and cards in `science/tutorial`, screens in `client/gui/tutorial`.

**Five largest problems**

1. `FluidDeviceScreen` (1 581 lines; 42 lines over 200 characters, up to 479) does four jobs in one class: the frame, eight pages addressed by magic ints, about 120 lines of per-kind meters with physics arithmetic, and English parsing of the engine's status. It also re-implements `KitDoor`, and it is the last screen with vanilla buttons, bordered edit boxes, a second scroll bar (`ProcessScroll`) and cut table cells (C1, C2, C3, C18, C21).
2. Only `ProcessSimulatorScreen` draws its frame in one batch. The other eight kit screens pay 13 draw calls for each panel button and about 6 for each meter. The device screen's Overview comes to an estimated 300 draw calls per frame, and about 20 to 40 with a batch (C4).
3. Each screen repeats the same plumbing: input routing (9 screens), the name entry (4), rebuild signatures (5), and placing every column again on every frame (C5 to C8).
4. Client watch sets are written six times. `CellWatch` already generalised two of them, and the copies have drifted: three never ask again for a first state that was lost, and `TankRenderer` neither checks identity nor resets on a level change (C11, C12).
5. Dead and misplaced code. `CalculatorColumn` still carries the removed calculator screen's frame and pages, which only tests keep alive. `Column.Metrics.DEFAULT` is drawn by no screen, but it is the metric the kit's own gate tests. `FluidGuiLayout`, which has no Minecraft classes, sits inside a Minecraft screen, and 7 builders import it from there (C9, C10).
